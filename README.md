# Armenian Phonetic

Տարբերակ՝ **1.0.0**։

Հայերենի հնչյունային մուտքագրում macOS-ի համար՝ համակարգային նշանների չափին համապատասխան **HY** նշանով։ Նշանը վեկտորային է, ունի թավ գրություն և հարմարվում է համակարգի բաց ու մուգ տեսքին։

Ստեղների աղյուսակը վերցված է Ukelele-ով ստեղծված սկզբնական հայկական դասավորությունից։ Հավելվածը ինքնուրույն է․ տեղադրված Ukelele կամ հին դասավորության փաթեթ անհրաժեշտ չէ։

## Պահանջներ

- Apple Silicon համակարգիչ՝ arm64 ճարտարապետությամբ։
- macOS 27.0 կամ ավելի նոր տարբերակ։ Գործնական ստուգումն իրականացվել է macOS 27.0.1-ում։
- Աղբյուրներից կառուցելու համար՝ Xcode Command Line Tools։ Արտաքին գրադարաններ անհրաժեշտ չեն։

## Տեղադրում

1. Բացեք `ArmenianPhonetic-1.0.0-arm64.pkg` տեղադրիչը և հետևեք քայլերին։
2. Հավելվածն ինքնաշխատ կտեղադրվի ընթացիկ օգտվողի `~/Library/Input Methods/Armenian Phonetic.app` պանակում։
3. Դուրս եկեք macOS-ի օգտահաշվից և նորից մուտք գործեք։
4. Բացեք համակարգի կարգավորումները՝ Ստեղնաշար → Տեքստի մուտքագրում → Խմբագրել։
5. Սեղմեք «+», որոնեք **Armenian Phonetic** և ավելացրեք այն։
6. Ընտրեք **Armenian Phonetic** մուտքագրման աղբյուրների ցանկից։

Տեղադրիչը ֆայլերը պատճենում է անհրաժեշտ տեղը։ Աղբյուրի ավելացումն ու ընտրությունը կատարում է օգտվողը՝ macOS-ի կարգավորումներում։

Հավելվածն ունի տեղային՝ ad-hoc ստորագրություն։ PKG-ն այս փուլում Developer ID վկայականով ստորագրված չէ և չի անցել Apple-ի նոտարական ստուգումը։

## Կառուցում

Հավելվածը կառուցելու համար նախագծի պանակից գործարկեք․

```sh
./scripts/build.sh
```

Արդյունքը՝ `build/Armenian Phonetic.app`։

PKG տեղադրիչը կառուցելու համար գործարկեք․

```sh
./scripts/package.sh
```

Արդյունքը՝ `dist/ArmenianPhonetic-1.0.0-arm64.pkg`։ Այս հրամանը նախ կառուցում է նաև հավելվածը։ Ֆայլի անունը հետևում է `[name]-[version]-[architecture].pkg` ձևաչափին։ Տարբերակը վերցվում է հավելվածի `Info.plist`-ից, իսկ ճարտարապետությունը՝ կառուցված գործարկվող ֆայլից։

## GitHub Actions

`.github/workflows/build-pkg.yml` աշխատանքային հոսքը PKG-ն կառուցում է յուրաքանչյուր `push`-ի և `pull_request`-ի ժամանակ։ Այն կարելի է գործարկել նաև ձեռքով՝ պահոցի **Actions → PKG-ի կառուցում → Run workflow** բաժնից։

Ստացված `ArmenianPhonetic-1.0.0-arm64.pkg` ֆայլը հասանելի կլինի ավարտված գործարկման **Artifacts** բաժնում՝ անմիջապես ներբեռնման համար։

`v1.0.0` ձևաչափով թեգի `push`-ի դեպքում հաջող կառուցումից հետո ինքնաշխատ ստեղծվում է **GitHub Release**, որին կցվում է պատրաստի PKG-ն։ Թեգի տարբերակը պետք է համընկնի `Resources/Info.plist`-ում նշված հավելվածի տարբերակին։ Սովորական ճյուղերի `push`-երը, `pull_request`-ները և ձեռքով գործարկումները միայն կառուցում են փաթեթը և պահպանում այն **Artifacts** բաժնում։

Օգտագործվում է GitHub-ի [`xcode-27`](https://github.com/actions/runner-images/blob/main/images/macos/xcode-27-arm64-Readme.md) arm64 միջավայրը՝ macOS 27 SDK-ով։ Այդ միջավայրը ներկայում նախնական հասանելիության փուլում է։

## Ինչպես է աշխատում

Հավելվածն օգտագործում է Apple-ի InputMethodKit-ը։ Սկզբնական դասավորության՝ macOS-ի կողմից կազմարկված աղյուսակը ներառված է հավելվածում։ `UCKeyTranslate` համակարգային գործառույթը ստեղնի կոդն ու Shift, Option և Caps Lock վիճակները փոխակերպում է համապատասխան նիշի։

Command և Control պարունակող համակցությունները փոխանցվում են հաճախորդ հավելվածին։ Նավարկման և խմբագրման հատուկ ստեղները նույնպես փոխանցվում են հաճախորդին։

HY նշանը 22 × 16 կետ չափով PDF է։ Թափանցիկ տառերը թույլ են տալիս macOS-ին գունավորել նշանը՝ ըստ համակարգի տեսքի։

## Նախագծի ֆայլերը

| Ֆայլ | Նպատակ |
| --- | --- |
| `Source/main.m` | Մուտքագրման մեթոդի կոդը։ |
| `Source/make-icon.swift` | HY նշանի գեներատորը։ |
| `Source/Armenian.keylayout` | Սկզբնական, Ukelele-ով խմբագրվող դասավորությունը։ |
| `Resources/Armenian.uchr` | Կազմարկված աղյուսակը, որն օգտագործվում է մուտքագրման ժամանակ։ |
| `Resources/Info.plist` | Հավելվածի և մուտքագրման աղբյուրի տվյալները։ |
| `installer/` | Տեղադրիչի նկարագրությունն ու հայերեն տեքստերը։ |
| `scripts/` | Հավելվածի և տեղադրիչի կառուցման հրամանները։ |

`Armenian.keylayout`-ի փոփոխությունը ինքնաբերաբար չի փոխում `Armenian.uchr`-ը։ Դասավորությունը փոխելու դեպքում պետք է նաև թարմացնել կազմարկված աղյուսակը։

## GitHub-ում տեղադրելու համար

Պահոցում ներառեք սկզբնական կոդը, ռեսուրսները և կառուցման հրամանները։ `.gitignore`-ը բացառում է `build/`, `dist/` և `.DS_Store` ֆայլերը, որպեսզի կառուցման արդյունքները չներառվեն պահոցի պատմության մեջ։ Պատրաստի PKG-ն կարելի է ներբեռնել Actions-ի արդյունքներից կամ առանձին ավելացնել GitHub-ի թողարկման ֆայլերին։

## Ստուգում

Գործնական ստուգմամբ հաստատվել են `A S D F` ստեղներով «ասդֆ» մուտքագրումն ու HY նշանի լայնությունը։ Հավելվածի կազմարկված աղյուսակը համեմատվել է սկզբնական դասավորության աղյուսակի հետ՝ բայթ առ բայթ։

## Հեռացում

Նախ ընտրեք մեկ այլ մուտքագրման աղբյուր։ Համակարգի կարգավորումներում հեռացրեք **Armenian Phonetic**-ը աղբյուրների ցանկից, ապա հեռացրեք `~/Library/Input Methods/Armenian Phonetic.app` հավելվածը։
